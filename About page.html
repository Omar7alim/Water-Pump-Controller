Water Pump Controller

About the system - monitoring, automation, and safety

Overview

The Water Pump Controller System is a web-based platform that monitors and controls pump station operations using real-time sensor data. It maintains the required water level efficiently while reducing manual effort, human error, and operational costs.

Key Features

  • Live dashboard for water level, flow rate, and pump status.
  • Automatic control: computes required level/flow and optimizes pump operation.
  • Manual control: engineers can select a pump and set ON/OFF, speed, and power.
  • Safety checks to prevent operation beyond safe limits.
  • Lifetime monitoring with maintenance notifications when hour limits are reached.
  • Alert system for warning, maintenance, and emergency events.

Control Logic
The system reads sensor values continuously, then updates the dashboard with live information. In Auto Mode, it calculates the required water level and flow, selects the number of pumps, adjusts speed and power, performs safety checks, and runs pumps accordingly. In Manual Mode, an engineer selects a pump and sets ON/OFF, speed, and power, then the system validates safety before executing the command.
The system can estimate required flow using two approaches:
  • Empirical (Mathematical) Method: uses hydraulic equations and known system parameters.
  • Trial & Error Method: starts at low speed then increases/decreases based on sensor feedback until targets are reached.
Each pump component has an expected lifetime measured in operating hours. The platform records operating time automatically and generates maintenance alerts when limits are reached, helping reduce downtime and increase reliability.
The alert system identifies events and notifies the engineer:
Warning: high usage
Maintenance: before failure
Emergency: overload/malfunction
In emergency cases, the system can stop the pump to prevent damage and keep the station safe.
